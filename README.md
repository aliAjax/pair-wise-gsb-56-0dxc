# 出口管制技术资料审批与许可核对平台

面向出口业务人员和合规人员的本地审批工作台。项目使用 React、Ant Design、Redux Toolkit、RTK Query、React Router、Vite 和 TypeScript 构建。

## 功能

- 提交图纸、技术说明、软件包、收件方、最终用途、技术参数、人员范围和声明。
- 按资料分类、国家地区、技术参数和人员范围匹配许可规则，解释缺失声明和升级审批原因。
- 拆解资料包并管理文件版本，逐页标记资料分类、受控技术和脱敏状态。
- 新文件版本不复用旧版分类结果；审批引用版本与现行版本不一致时阻断流程。
- **续办对账批次**：送审时固化资料包版本、文件引用版本与逐页脱敏摘要，生成可续办批次。
  - 许可平台回执晚到可继续等、重复回执按回执编号全局只入一次；回执版本与固化版本不一致时批次停在“待核”，不放行。
  - 文件换版只让依赖该文件的**待审批步骤**与**未核验回执**失效重算；已确认意见和已核验回执（许可记录）保留；已放行批次永不回滚。
  - 每步确认使用 CAS 令牌，两人同时确认只有一个写入成功。
  - 写入失败把完整批次（必要时含整份工作区快照）存入“续办箱”，从完整批次重试；revision 冲突时拒绝覆盖。
  - 旧数据缺逐页摘要时按首次送审内容自动回填并标记；引用版本已丢失、补不全的批次保持阻断，绝不放行。
  - 审批页、版本差异页、审计导出均展示同一对账批次。
- 按规则等级生成顺序审批路线，支持审批通过、逐项意见、多轮退回和重新发起。
- 审批完成后核对额度并扣减，高风险结论或额度不足时拒绝执行。
- 比较资料包版本、跟踪文件版本差异、导出追溯 JSON 和审计 CSV。

本地模拟服务位于 RTK Query 的 `baseQuery` 中，数据保存到浏览器 `localStorage`；写入失败的续办箱使用独立 outbox 键。

## 运行

```bash
npm install
npm run dev
```

开发服务地址：`http://localhost:18456`

## 构建

```bash
npm run build
npm run preview
```

## 行为验证

```bash
npm run test:engine   # 对账引擎：去重/待核/选择性失效/CAS/放行/旧数据回填/整批重试
npm run test:api      # mockBaseQuery 端到端：失败入箱、整批重试、并发确认、换版快照一致
```

## 目录

```text
src/
  app/         Redux Store、UI Slice、RTK Query API 与类型化 Hooks
  components/  应用外壳、页面头、状态标签、批次/回执状态标签
  features/    总览、资料包、逐页核对、审批、回执对账、许可、版本差异、审计
  services/    模拟数据、许可规则、校验与差异引擎、对账批次引擎、本地存储
  types/       领域类型
scripts/       对账引擎与 API 的行为验证脚本（npm run test:engine / test:api）
```
